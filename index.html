Issues & Recommendations
Detected data quality issues across all 4 tables
⚠️ CBP Amount Fields are All NULL

Both tblCBPMessFeeCollection and tblCBPHostelFeeCollection have Amount = NULL for all 1,606 records. Fee amounts need to be backfilled from TblFeeDetails via enrollment number join.

⚠️ Gender Case Inconsistency in StudentTbl

Gender values include 'MALE', 'Male', 'FEMALE', 'Female' — four variants for two categories. Recommend standardizing to title case ('Male'/'Female') for clean reporting.

⚠️ NoOfPapers Column is 100% NULL

TblFeeDetails.NoOfPapers has 31,784 NULL values — every row. This column appears unused and can be safely dropped or archived.

⚠️ Branch Column is 99.97% NULL in StudentTbl

Only 1 out of 2,988 students has a Branch value. This column is either not applicable to MBA students or was never populated.

✅ Zero Duplicate Rows

All four tables are free of exact duplicate rows. No removal was required during cleaning.

✅ All Students Active

StudentTbl shows IsActive = TRUE for all 2,988 students with zero inactive accounts in the dataset.
